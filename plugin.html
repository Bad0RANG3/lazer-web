02 / SUBMIT — 上架规则 FORK / EDIT JSON / PULL REQUEST

上架，
只要一个 PR。

插件市场不开放自动提交。Fork 仓库，编辑 public/plugin/plugins.json，用上架模板发一个 Pull Request；合并之后，客户端就会读到你的插件。

01

开源插件

必须带上公开可访问的开源仓库链接与许可证。客户端可直接从仓库的 Releases 获取更新，不需要为每个版本重复提交。

REPO REQUIRED
02

闭源插件

可以不带仓库链接，但作者必须在每一次更新时提交 PR，修改 plugins.json 里的版本、下载地址与校验值。

PR EVERY RELEASE
03

审核上架

维护者会检查字段完整性、许可证与下载地址。合并后的 main 分支会由 Vercel 自动构建，/plugin/plugins.json 随即生效。

MERGED = LIVE
可选 / ZIP 托管

作者可以选择把插件 ZIP 上传到插件市场：将 ZIP 放进 public/plugin/<作者>/<插件 id>/<版本>/，download 填市场地址即可。
